# Documentation Style

## Objective

Keep project documentation concise and factual.

## Rules

1. State the subject directly.
2. Prefer one sentence over two when meaning is preserved.
3. Remove introductory justification.
4. Remove promotional adjectives.
5. Avoid rhetorical contrasts such as "not merely X, but Y".
6. Use terminology consistently.
7. Preserve technical identifiers in their conventional form.

## Before writing

Ask:
- Is this information necessary?
- Is this sentence describing or persuading?
- Can the same information be expressed more directly?

## Example

Avoid:

> Este proyecto no es únicamente un repositorio de notas...

Prefer:

> Este repositorio contiene la investigación de presencia digital de AMC Solutions.
